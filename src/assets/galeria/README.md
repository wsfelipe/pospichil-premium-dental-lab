# Galeria — Laboratório Pospichil

Adicione fotos reais aqui (`src/assets/galeria/`). Elas aparecem automaticamente na seção **Galeria** do site.

## Convenção de nome

`categoria__titulo-do-caso.jpg`

- **categoria** e **titulo** separados por **dois underlines** (`__`).
- Palavras dentro da categoria/título separadas por **hífen** (`-`).
- Extensões aceitas: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.

### Exemplos

| Arquivo                                          | Categoria         | Título exibido           |
| ------------------------------------------------ | ----------------- | ------------------------ |
| `coroas__zirconia-superior-caso-1.jpg`           | Coroas            | Zircônia superior caso 1 |
| `protocolo__inferior-acrilico.jpg`               | Protocolo         | Inferior acrílico        |
| `facetas__lentes-anteriores.webp`                | Facetas           | Lentes anteriores        |
| `laboratorio__bancada-acabamento.jpg`            | Laboratório       | Bancada acabamento       |
| `equipe__protetico-cad-cam.jpg`                  | Equipe            | Protético CAD/CAM        |

## Recomendações

- Resolução: 1200–2000 px no lado maior.
- Formato preferido: **WebP** (menor peso, mesma qualidade).
- Fundo neutro e iluminação difusa para destacar a peça.
- Evitar nomes com acentos ou espaços.

Enquanto a pasta estiver vazia, o site mostra placeholders elegantes em grafite — basta adicionar as imagens para substituí-los.
